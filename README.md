# DevOpsR4 — Git Practice Archive

Small training repository from early DevOps/Git exercises.

## What this repo is

The text files in this repository were used to practice basic Git workflows such as creating files, staging changes, committing, and working with repository history.

## What this repo is not

This is **not** a production project or representative infrastructure implementation. I keep it public as a learning-history artifact.
